## Candidate capsule (fixed before dispatch)

Base is the commit containing this plan and protected oracle, on feat/oauth-pkce-dev-probe. One attempt, at most one bounded correction wave before escalation; expected 15 minutes implementation and 10 minutes senior review, report overruns rather than pretend enforcement. One implementer owns only `apps/api/scripts/check-external-oauth-login.mjs` and `apps/api/test/oauth-login.test.mjs`. Integrator owns package script, protected oracle, docs and publication. No worker subagents/global edits. Independent checks and reviewer decide acceptance, never candidate self-report.

Public dev constants: issuer `https://whatfees.ca.auth0.com/`; JWKS `https://whatfees.ca.auth0.com/.well-known/jwks.json`; clientId `iJ91FR4M6AIgD8P68qPQ8Zpo3BgO8Qhe`; callbackUrl `http://127.0.0.1:8787/callback`. This is a development client, not a production external client allowlist or browser migration. Do not accept arbitrary issuer/callback/client arguments or environment bypasses.

Export frozen `DEV` with those four fields, and `createPkceAttempt({fetchImpl = globalThis.fetch, now = Date.now} = {})`. Return a frozen object `{authorizationUrl, finish(callbackUrl)}`. The attempt owns private fresh random verifier/state/nonce (32 random bytes each), S256 challenge and five-minute deadline. Request exactly code/query/openid with that callback, state, nonce and challenge; no offline_access, API audience/resource or client secret. No verifier in authorization URL.

`finish` rejects unsafe callback URLs (exact scheme/host/port/path, canonical URL, no fragment, bounded length, duplicate parameters), wrong/missing state or issuer, provider denial, expired attempt and second/concurrent consumption. Invalid state must not reach token exchange. A matching callback is consumed before any await and never reactivated on network/verification failure. Pinned issuer's `iss` parameter is required; issuer advertises it. Reject mixed code/error. Typed failure need only fixed `Error("OAuth login check failed.")` without input/cause/details.

Exchange only to pinned `/oauth/token`: POST application/x-www-form-urlencoded with grant_type, client_id, redirect_uri, code and original code_verifier. No secret. Fetch redirects forbidden, at most 10 seconds/network request, bounded actual JSON body 64KiB (not just Content-Length). JWKS fetched only at pinned URL with same redirect/size/time limits; use maintained jose createLocalJWKSet/jwtVerify, no custom crypto. Reject missing/malformed ID token or an unexpected refresh token. ID token: RS256 signature, exact issuer, singleton audience=clientId, bounded nonempty subject, required finite ordered iat/exp, current expiry and freshly issued iat (five minutes, 30sec skew), exact original nonce, optional azp must equal clientId. Check injected clock in verification. If at_hash is present, verify it against the token response's access_token using RS256 hash rules. Return only frozen `{status:"pkce_login_verified",activationReady:false}`; expose no claims, subject, code or token.

CLI no args: bind only 127.0.0.1:8787, start listening before printing authorizationUrl. No auto-browser launching or files. Receive only exact Host, GET callback path, bounded request URL; wrong requests get fixed safe 4xx, irrelevant requests must not consume the attempt. Five-minute overall deadline, network limits, clean server/socket shutdown on completion/failure/SIGINT; fixed success JSON and redacted failures; no provider pages/raw causes/callback URL/token/claims printed. `--help` fixed usage and no listener; reject all other args. Signing keys/code/refresh are provider-owned. No access token ever sent to WhatFees. Browser and listener must run on same desktop; a phone's loopback is not this execution host.

Candidate supplemental tests must include a real in-process loopback listener success/failure and cleanup, signed token negative cases, duplicate/malformed callback, concurrent/repeated consumption, bounded body/network failures and CLI argument/redaction behavior. Protected Node oracle (integrator-owned) covers request binding, code verifier, signature/issuer/audience/nonce, pre-network rejection and single use. API hook registers both test files. Run `npm run verify:api`, `npm --prefix apps/api run verify:ci`, and `npm run security:scan`; UTC QA preload for known host timezone issue, existing thresholds unchanged. No shared tooling/runtime dependency changes, no full web tests needed for API-only increment.
